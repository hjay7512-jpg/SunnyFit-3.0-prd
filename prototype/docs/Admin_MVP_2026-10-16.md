## 业务规则入口

后台右上角 **Business rules** 打开独立的 `/business-rules` 页面。链接携带当前模块、规则主题、关系节点和返回地址；进入后定位模块说明，再展示相关业务图。后台侧栏保持操作入口，Demo Overview 展示场景数据。旧的 `overview?tab=logic` 链接仍可跳转。

默认收起每页的实施范围说明，仅保留位置与阶段标记，减少对操作界面的干扰。

## 课程范围操作

入口：[在线 Course Management](https://hjay7512-jpg.github.io/SunnyFit-3.0-prd/prototype/#/commercialization/content)。

1. 按内容类型、内容 Scope、状态和 ID / 名称筛选。
2. 行内 **Set Scope** 修改单条内容。已发布配置和待发布范围分别显示。
3. 勾选多条后 **Set Content Scope** 批量设置。Course、World Tour、Training Program 分别选择所属权益项的有效范围。
4. 保存仅产生草稿。默认保持商业标签，跳过未变更条目；其他已有草稿字段保留。
5. 核对后 **Publish Selected Drafts** 发布全部已保存草稿字段。批次内任一记录冲突或无效，整个批次不生效。

新 Scope 不自动加入现有 Suit。发布内容范围也不会改写已购买权益的版本快照。关闭或切换筛选时，勾选状态清空，避免对隐藏条目批量操作。

## 对照来源与还原边界

从 [现有后台](https://d3ce3i7hi04m3a.sunnyfitapp.com/sunny-admin/index.html#/market/banner) 的公开前端资源确认：

- 课程列表路由 `/course/index`，Training Program 路由 `/course/package`。
- 课程列表采用分组筛选、列表勾选、工具栏、表格和右侧操作列；原列表包含课程 ID、缩略图、名称、分类、状态及更新时间等字段。
- 本轮延续这一结构与现有 Vue / Element UI 样式，围绕商业化范围增加筛选、单条和批量编辑。
- 读取依据为公开资源 `app.aa4fa6e7.js`、`chunk-66ea790d`、`chunk-7e416e56`，未读取线上业务记录。当前会话未获得可调用的已登录 Chrome 标签页接口，因此尚未完成登录态画面的逐像素核对。完整媒体编辑器、运营筛选字典及 Program 编排未在本轮重新实现；没有接入的缩略图使用空状态。
