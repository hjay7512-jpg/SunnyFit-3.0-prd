## 业务规则入口

后台右上角 **Business rules** 打开独立的 `/business-rules` 页面。链接携带当前模块、规则主题、关系节点和返回地址；进入后定位模块说明，再展示相关业务图。后台侧栏保持操作入口，Demo Overview 展示场景数据。旧的 `overview?tab=logic` 链接仍可跳转。

默认收起每页的实施范围说明，仅保留位置与阶段标记，减少对操作界面的干扰。

## 权益内容管理

入口：[权益管理 → 内容管理](https://hjay7512-jpg.github.io/SunnyFit-3.0-prd/prototype/#/commercialization/content-management)。

1. 选择 Course、World Tour 或 Training Program 等内容类型，查看该类型的范围标签。
2. 新建或编辑该类型的范围标签；选择标签后，右侧显示关联内容。
3. 点击 Add from 对应内容库，只能选择当前类型的内容，支持一次添加多条。
4. 已在当前范围的内容不可重复选择。从其他范围添加时，确认替换旧关联；每条内容只保留一个范围归属。
5. 可将单条内容 Move 到同类型的另一个范围，不提供会导致内容失去唯一归属的直接解除操作。

关联保存后立即生效并记录内容版本。只更新范围关系，保留商业标签及其他资料；已有草稿的无关字段不会被发布。冲突或跨类型条目会使整个批次回滚。新范围不会自动加入已有 Suit。

原内容库中已移除通用 Set Scope 和混合类型批量入口；各内容类型分别展示范围归属，范围字段从权益内容管理统一维护。

## 对照来源与还原边界

从 [现有后台](https://d3ce3i7hi04m3a.sunnyfitapp.com/sunny-admin/index.html#/market/banner) 的公开前端资源确认：

- 课程列表路由 `/course/index`，Training Program 路由 `/course/package`。
- 课程列表采用分组筛选、列表勾选、工具栏、表格和右侧操作列；原列表包含课程 ID、缩略图、名称、分类、状态及更新时间等字段。
- 本轮延续这一结构与现有 Vue / Element UI 样式，按各内容库展示归属，关联维护独立放在权益管理 → 内容管理。
- 读取依据为公开资源 `app.aa4fa6e7.js`、`chunk-66ea790d`、`chunk-7e416e56`，未读取线上业务记录。当前会话未获得可调用的已登录 Chrome 标签页接口，因此尚未完成登录态画面的逐像素核对。完整媒体编辑器、运营筛选字典及 Program 编排未在本轮重新实现；没有接入的缩略图使用空状态。
