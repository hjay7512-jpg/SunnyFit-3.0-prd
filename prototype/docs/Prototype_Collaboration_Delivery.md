# 原型协作数据库交付记录

原型区块右键打开协作菜单，鼠标移动时菜单保持固定，点击外部或 Esc 关闭。左键继续体验原型；文案按字段编辑、按区块保存和记录版本。文案、评论和版本记录由共享服务保存。代码发布不会覆盖数据库中的团队文案。

课程、World Tour、Program 的开始按钮默认只编辑当前展示的 CTA。右侧可选择关联流程位置、查看触发条件与继承后的实际文案，并在中间原型定位具体文字。流程预览保留跨位置草稿，复用真实组件，购买与继续操作只切换展示，不更改业务数据。预览中的公共文案可直接改选编辑，返回时恢复原付费墙与阅读位置。详见协作 SOP。

## 已发布的协作服务

- 服务：[SunnyFit 原型协作服务](https://sunnyfit-prototype-collaboration.sunnyfit-9441.chatgpt.site)
- 存储：Sites 托管的 Cloudflare D1。
- 服务版本：2；源码提交 `3ec425987a637af5546090f156b7b159aa9fd772`。
- 当前契约：29 个运营文案区块、213 个文案字段，以及 19 个页面备注区块。
- GitHub Pages 通过公开接口读取生效文案；评论默认面向所有访问者开放；文案修改、历史、解决评论和管理接口校验服务端权限。
- 授权链接不写入仓库。本轮已按用户批准发放给 JayH 的编辑链接有效期为 30 天，至 2026-11-20 10:30（中国标准时间）；实际范围与撤销状态以服务端记录为准。

- D1 仿真环境通过实际迁移、授权、原子版本保存与评论检查。
- 原有三栏评审 13 项、付费墙 13 项、计划与运动结果流程 16 项回归通过。
- 前端、GitHub Pages 产物、服务构建及服务 TypeScript 检查通过。前端保留原有资源体积提示。

## 线上复核

服务发布成功后已验证健康接口、生效文案协议和 GitHub 来源的 CORS 配置。前端发布与后续核验由 GitHub Actions 和 `deployment.json.sourceCommit` 对齐；完整线上结果由发布脚本另存于 `runtime/github-prototype-deployment-*/`，不将本地验证冒充线上通过。

操作步骤和后续发布、迁移、回滚约定见 [原型协作 SOP](Prototype_Collaboration_SOP.md)。
